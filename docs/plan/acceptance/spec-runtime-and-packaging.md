# Acceptance: `docs/spec/runtime-and-packaging.md` Requirements

One row per Requirement bullet, in source order. R16 is split in two (R16a, R16b) because its two halves have different evidence; the other rows are one per bullet, numbered in source order. Notes that are not evidence sit in this paragraph, not in the rows: (a) R10: the reference server's own `ws` pin in `games/reference-server/package.json` has no test. (b) R14: Node >= 22 is the repo's own `engines` (`>=22.18`) under which every suite runs; nothing asserts the version; the Deno test prints `deno-missing` and passes without Deno unless `REQUIRE_DENO=1`, which is the best-effort contract. (c) R7 and R15: `deployed/coi-and-online @slow` is skipped without `DEPLOYED_URL`. (d) R7: Durable Objects are a measured no-go (ADR 0051), so that host is not claimed. (e) R17: the 1,000,000 B warn is a console warning by design; the assertion is the fail budget. Device checks cited below are all unticked in `docs/plan/device-checks.md` at the time of writing.
